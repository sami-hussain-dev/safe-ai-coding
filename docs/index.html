safe-ai-coding for Claude Code

A free, open-source skill that makes AI coding agents safe: it asks before anything risky and explains the harm, catches the mistakes AI makes, and reviews every change like a careful teammate.

Get it on GitHub Quick start guide (PDF)

Install

Option 1: Claude Code plugin (recommended)

Type these two lines inside Claude Code:

/plugin marketplace add sami-hussain-dev/safe-ai-coding
/plugin install safe-ai-coding@safe-ai-coding

Option 2: with git (any Claude Code version)

# macOS, Linux or Git Bash
git clone --depth 1 https://github.com/sami-hussain-dev/safe-ai-coding.git ~/safe-ai-coding
cp -r ~/safe-ai-coding/skills/safe-ai-coding ~/.claude/skills/

# Windows PowerShell
git clone --depth 1 https://github.com/sami-hussain-dev/safe-ai-coding.git "$HOME\safe-ai-coding"
Copy-Item -Recurse "$HOME\safe-ai-coding\skills\safe-ai-coding" "$HOME\.claude\skills\"

Start a new Claude Code session. That is all. Pick one option, not both. With the git copy, the command is /safe-ai-coding instead of /safe-ai-coding:safe-ai-coding.

What it does

Asks before harm

Installs, CDN scripts, database writes, deleting files, git pushes, secrets, data leaving the machine: the agent explains the possible damage, whether it can be undone and a safer option, then waits for your yes. Everything else just runs, unless you choose strict mode.

Catches AI mistakes

Hallucinated classes, methods, routes, views and imports; "rest of the code unchanged" placeholders; SQL and command injection; leaked keys; destructive migrations; weakened tests.

Protects the agent

Scans repositories for prompt-injection text in CLAUDE.md, AGENTS.md and rules files (also in dependencies), malicious git config and hooks, install scripts and hidden unicode.

Reviews and reports

Every change is reviewed through an AI lens and a human lens. On request, a polished PDF report shows what was wrong, what was fixed and the evidence.

Frequently asked questions

How do I make Claude Code safer?

Install safe-ai-coding, and add permission rules in .claude/settings.json for commands you never want run without asking.

Can it detect AI hallucinations in code?

Yes: it checks that the classes, methods, views, routes, config files and imports used in new code exist in your repository.

Does it protect against prompt injection?

Yes: content is treated as data, and instruction files are scanned for hidden or malicious instructions.

Does it send my code anywhere?

No. Everything runs locally and it never executes repository code.
