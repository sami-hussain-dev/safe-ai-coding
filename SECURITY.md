# Security policy

If you find a way to bypass safe-ai-coding, or a way to make its scripts run untrusted code, please report it privately to **samihussain9t9@gmail.com** instead of opening a public issue.

Please include:

- the steps to reproduce it
- the version (see `skills/safe-ai-coding/VERSION`)
- your operating system

You will get a reply as soon as possible, and fixes are credited in the changelog unless you prefer otherwise.

Maintainer: Sami Hussain, x8code.com
